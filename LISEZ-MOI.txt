VP PRIMEUR – SITE WEB + FACTURATION
===================================

Adresses (GitHub Pages)
-----------------------

Facturation :    https://b4b428.github.io/VPPrimeurs/facturation.html
                 (mettez ce lien dans vos favoris ; il n'apparaît pas sur le site)

Contenu
-------
index.html            la page d'accueil du site
facturation.html      l'outil de facturation
js/infos.js           >>> VOS INFORMATIONS : adresse, horaires, téléphone… <<<
js/site.js            fonctionnement du site (ne pas modifier)
css/site.css          mise en forme du site
js/app.js, css/style.css, js/vendor/   l'outil de facturation
img/                  logo (et vos photos)

Mettre à jour vos informations
------------------------------
1. Sur GitHub, ouvrez js/infos.js puis cliquez sur le crayon (Edit).
2. Remplissez les champs entre les guillemets '…'.
   Un champ laissé vide n'apparaît pas sur le site.
3. Cliquez sur « Commit changes ». Le site se met à jour en 1 à 2 minutes.

Ajouter une photo
-----------------
1. Envoyez la photo dans le dossier img (Add file > Upload files),
   par exemple img/margot-damien.jpg (pas d'espaces ni d'accents dans le nom).
2. Dans js/infos.js :  photo: 'img/margot-damien.jpg',

Formulaire « professionnels »
-----------------------------
Il ouvre la messagerie du visiteur avec une demande déjà rédigée,
adressée à l'e-mail indiqué dans infos.js. Sans e-mail renseigné,
il invite à appeler ou à passer au magasin.
